Tasty Bites — Restaurant Landing Page

A simple restaurant landing page built as part of my journey into frontend web development.

This project was created to practice the fundamentals of HTML and CSS while building a complete restaurant website layout from scratch. It includes different sections commonly found on a restaurant website, such as a hero section, about section, popular dishes, testimonials, food gallery, blog posts, and footer.

---

📌 Project Overview

Tasty Bites is a fictional restaurant website designed to provide a simple and attractive online presentation for a restaurant.

The main goal of this project was to practice structuring a webpage with HTML and styling the different sections with CSS.

Through this project, I worked on arranging content, images, navigation links, buttons, cards, testimonials, galleries, and a multi-column footer.

🧩 Main Sections

- Hero Section

The hero section introduces the restaurant with a background food image, a short welcome message, and a call-to-action button.

- About Us

This section provides a short introduction to Tasty Bites and includes images to make the section more visually appealing.

- Popular Dishes

A collection of food cards displaying some of the restaurant's popular dishes and their prices.

- Testimonials

A simple customer testimonial section containing customer images, comments, names, and roles.

- Food Gallery

A visual gallery showcasing different food images in a structured layout.

- Recent Articles

A blog-style section containing sample restaurant articles with dates, comments, short descriptions, and "Read More" links.

- Footer

The footer contains:

- Restaurant description
- Social media links
- Useful links
- Opening hours
- Contact information
- Copyright information

---

💭 Challenges

As a beginner, one of the main challenges was getting the different sections to look the way I wanted them to.

I had to experiment with CSS properties such as "display", "gap", "margin", "padding", "width", and alignment to understand how they affected the layout.

The footer section, in particular, required some adjustments to get the different columns and content properly arranged.

These challenges helped me understand that building a webpage is not only about writing code, but also about testing, observing the result, finding problems, and making improvements.
