# Tasty Bites Restaurant Landing Page 🍽️

A landing page built as a learning assignment to practice front-end web development fundamentals.

## 📖 About

This project is a beginner-level assignment focused on building the basic HTML skeleton of a restaurant website. The goal is to practice structuring a webpage using semantic HTML and <div> tags — organizing content into clear, clean and meaningful sections.

This is a work in progress as I continue on my journey of learning front-end web development.

## ✨ Sections Included

- Header — Brand logo and navigation bar
- Hero — Catchy headline and direct call-to-action
- About Us — Restaurant description and backstory
- Popular Dishes — Featured tasty dishes
- Food Gallery — Images of delicious foods
- Reviews — Featured testimonials from satisfied customers.
- Contact / Footer — Contact details and closing info

## 🛠️ Tech Used

- HTML5 (main focus of this assignment)
